# CodeRabbit Review Protocol

Always actively inspect and address all reviews, comments, and change requests provided by CodeRabbit:
1. **Fetch Reviews & Comments**: Check GitHub PR reviews, inline review comments, and commit comments from CodeRabbit using `gh api` or `gh pr view --comments`.
2. **Analyze & Validate**: Examine all findings (security vulnerabilities, performance bottlenecks, race conditions, edge cases, type safety, and clean code suggestions).
3. **Implement Approved Changes**: Make the required code changes, verify with tests/build (`npm run build`), and push updates.
4. **Transparent Reporting**: Provide a clear summary of all CodeRabbit comments and how each was resolved.
